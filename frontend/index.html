YouTube Library

Add a YouTube Data API key and your channel to list your playlists on the Music screen automatically, and to enable search. Only public playlists can be listed — private ones need a signed-in browser session, which this device doesn't have.

YouTube Playlists (all, incl. Liked)

A one-time Google sign-in that lists every playlist you own, including Liked videos — not just public ones on a channel. Needs its own OAuth client (separate from the API key above); see README.md for the one-time setup in Google Cloud Console.
